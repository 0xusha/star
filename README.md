# Cosmic Starburst Animation ✨

A dynamic, mathematically generated cosmic starburst animation built using Python's Turtle graphics. The script calculates perfect star geometry and creates an infinite, pulsating loop of shooting light rays and glowing mini stars.

## ✨ Features
* **Procedural Geometry:** Calculates exact coordinates for a sharp, 5-pointed star and evenly spaces the rays along its perimeter.
* **Animated Light Rays:** Draws shooting straight lines step-by-step for a smooth, expanding visual effect.
* **Infinite Pulsation:** Continuously redraws the starburst with randomized thicknesses and celestial colors (cyans, golds, and whites) against a deep midnight background.

## 🚀 How to Run
This project uses Python's built-in `turtle` module, so no external dependencies are required!

1. Clone this repository or download the script.
2. Ensure you have Python installed on your system.
3. Run the script from your terminal:
   ```bash
   python star.py
